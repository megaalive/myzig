# EXT-STUDY-054 — finish external-study shortlists in one batch

## Pattern

When an agent proposes N external study targets, promote/ship all of them in
the same batch (or explicitly defer with a dated debt list). Leaving “optional
next” after naming concrete repos creates unpaid ownership debt.
