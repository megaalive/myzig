# AGENT-STUDY-002 — cadangan / link-only recommendations are unpaid debt

## Friction

An agent finished a primary shortlist (e.g. kernel 1–6) and answered as if the
batch were done, while the same answer had already named **cadangan kuat**,
**opsional**, or user-supplied links that were never cloned/surveyed/promoted.

## Rule

If the user or the agent lists a concrete repo (primary, cadangan, optional, or
link-only), it is part of the named set until promoted or explicitly dated as
debt (`EXT-STUDY-054`, `EXT-STUDY-062`, `F-AGENT-003`).

Clone blockers (git-lfs, invalid host paths) do not cancel the debt: survey via
API/raw and record the blocker (`EXT-STUDY-061`, `F-AGENT-004`).

`EXT-STUDY-055`..`063`.
